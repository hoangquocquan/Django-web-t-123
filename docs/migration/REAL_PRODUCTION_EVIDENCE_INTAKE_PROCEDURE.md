# Real Production Evidence Intake Procedure

## Purpose

This procedure explains how to receive, check and validate real production
traffic evidence before Legacy API shutdown can be considered.

This is an evidence-only workflow. It must not modify IIS, proxy settings,
routes, production code or databases.

## Required Input Files

Place evidence files in:

`docs/migration/production_evidence/input/`

Required files:

- IIS W3C raw logs in `docs/migration/production_evidence/input/iis_logs/`
- CSV export: `docs/migration/production_evidence/input/iis_api_evidence.csv`
- JSON evidence report generated by the validator

CSV columns must be:

```text
timestamp,source,client,endpoint,status_code,user_agent
```

## Required Collection Period

Minimum accepted period:

`7 days`

Recommended period:

`30 days`

The validator accepts an explicit period label through:

```powershell
python scripts\phase11_1_6_5_production_evidence_validator.py --period "2026-07-01 to 2026-07-30"
```

If no explicit period is provided, the validator tries to infer the period from
the timestamps found in the evidence records. If no timestamps exist, the
evidence package remains incomplete.

## Intake Steps

1. Copy reviewed IIS W3C logs into `docs/migration/production_evidence/input/iis_logs/`.
2. Export API rows to `docs/migration/production_evidence/input/iis_api_evidence.csv`.
3. Confirm the CSV has the required header and at least one data row.
4. Run the Phase 11.1.6.5 validator.
5. Review the generated JSON and Markdown evidence reports.

## Validation Rules

The package is complete only when:

- IIS logs exist.
- CSV export exists and contains at least one evidence row.
- Collection period is present.
- Required CSV fields are present.
- Legacy `/api/*` traffic count is `0`.
- Replacement Django `/api/v1/*` traffic count is greater than `0`.
- Unknown clients count is `0`.

## Output Files

The validator writes:

- `docs/migration/production_evidence/reports/REAL_PRODUCTION_EVIDENCE_REPORT.json`
- `docs/reviews/PHASE_11.1.6.5_PRODUCTION_EVIDENCE_REVIEW.md`

## Stop Conditions

Stop and keep Legacy API active when:

- IIS logs are missing.
- CSV export is empty.
- Required CSV columns are missing.
- Collection period is missing.
- Legacy `/api/*` traffic is detected.
- Replacement `/api/v1/*` traffic is not confirmed.
- Unknown clients are detected.

## Final Reminder

This procedure does not authorize shutdown. A complete evidence package must
still pass the final readiness gate and architecture review.
