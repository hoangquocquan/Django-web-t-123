# Wave 4 - Django Legacy Reduction And Final Ownership Assessment

## Objective

Audit remaining legacy dependencies, determine final Django ownership status, decide payment ownership, and create a legacy retirement strategy.

## Scope

- Legacy dependency audit
- Payment ownership decision
- Database ownership final review
- Legacy retirement plan
- AI Factory final review evidence

## DO NOT

- Delete legacy code
- Shut down legacy services
- Migrate payment without approval
- Perform destructive database changes
- Deploy production changes

## Implementation Tasks

- Review legacy backend folders, services, APIs, and database dependencies
- Classify remaining ownership as Django-owned, shared, or legacy-only
- Produce payment decision with risk and recommendation
- Produce retirement plan with prerequisites and rollback strategy
- Validate with Django check, migrations, pytest, and AI Factory

## Expected Output

```text
DJANGO_FINAL_OWNERSHIP_ASSESSMENT_COMPLETE
```
