# AI Software Factory V2

## Purpose

V2 separates the development workflow into clear AI-assisted roles so each step
is easier to audit and explain.

## Roles

- Requirement Analyzer
- Architecture Planner
- Code Reviewer
- Test Generator
- Security Reviewer
- Documentation Generator

## Flow

Requirement -> AI Planner -> Codex Development -> Automated Tests -> AI Code
Review -> Security Review -> Human Approval.

## Safety

- No production deployment.
- No automatic merge.
- No external AI API.
- Human approval is required.
