# Django Skeleton - Giai đoạn 3

Thư mục này là khung Django mới cho dự án MecPrecision.

Giai đoạn này chỉ tạo:

- `core`: settings, urls, asgi, wsgi.
- Các app rỗng: `accounts`, `products`, `customers`, `quotation`, `news`, `chatbot`, `ai`, `dashboard`, `common`.
- Thư mục `templates`, `static`, `media`, `tests`.

Chưa chuyển business logic từ `backend/app.py`.
