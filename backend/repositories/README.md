# Repositories

Repository là nơi thao tác trực tiếp với database.

Nếu muốn sửa câu SQL đọc/ghi dữ liệu, hãy tìm trong thư mục này.

Ví dụ:

- `products_repository.py`: SQL cho sản phẩm.
- `categories_repository.py`: SQL cho danh mục sản phẩm.
- `news_repository.py`: SQL cho tin tức.
- `contacts_repository.py`: SQL cho yêu cầu liên hệ.
- `users_repository.py`: SQL cho tài khoản quản trị.
- `settings_repository.py`: SQL cho cài đặt hệ thống.
- `public_repository.py`: SQL cho dữ liệu hiển thị ngoài website.
